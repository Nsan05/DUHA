# Data Access Instructions

The raw satellite data and processed files are too large to host on GitHub.
Please download them from the Project Google Drive.

**https://drive.google.com/drive/folders/1tyw4CMagENUEwCw_3vkB5nHzcJwYKfq0?usp=sharing**

## Directory Structure

Ensure your `data/` folder looks like this:

```text
data/
├── raw/                         <-- Input Archives (From Google Drive)
│   ├── landsat/
│   │   ├── lst/                 <-- Landsat 8/9 Band 10 TIFs
│   │   └── metadata/            <-- MTL.txt files
│   ├── sentinel2/
│   │   ├── scenes/              <-- .SAFE folders or unzipped .tif bands
│   │   └── metadata/
│   ├── viirs/
│   │   ├── daytime/             <-- VIIRS LST files
│   │   └── metadata/
│   ├── overture/                <-- Buildings.geojsonseq
│   └── boundaries/              <-- urban_dubai_communities.geojson
│
├── intermediate/                <-- Generated by src/features/ & src/masks/
│   ├── grids/                   <-- Master Grid & Reference Metadata
│   ├── sentinel2_30m/           <-- Processed Sentinel-2 layers (Albedo, NDVI)
│   ├── urban_form/              <-- Building/Road density rasters
│   └── masks/                   <-- Intermediate masks (sand, water, urban)
│
└── final/                       <-- THE GOLDEN DATASET (Read-Only for Phase 2)
    └── phase1_features/
        ├── albedo_30m.tif
        ├── ndvi_30m.tif
        ├── building_density_30m.tif
        ├── road_density_30m.tif
        ├── urban_mask_30m.tif
        ├── water_mask_urban_30m.tif
        └── ... (other aligned 30m features)
```

## Data Generation

The content of `data/intermediate` and `data/final` is generated by the scripts in `src/`.

1.  **Feature Generation**:

    - `src/features/sentinel2.py` -> Populates `sentinel2_30m/`
    - `src/features/buildings.py` -> Populates `urban_form/`
    - `src/features/roads.py` -> Populates `urban_form/`

2.  **Mask Generation**:

    - `src/masks/masks.py` -> Generates `urban_mask_30m.tif`
    - `src/masks/water_mask.py` -> Generates `water_mask_*.tif`
    - `src/masks/sand_mask.py` -> Generates `sand_mask_30m.tif`

3.  **Finalization**:
    - `src/pipeline/finalize_phase1.py` -> Validates and copies definitive files to `data/final/phase1_features/`.
